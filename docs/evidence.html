入口与帮助

req-cli — 华为云 CodeArts 需求管理工作项命令行工具

用法:
  req-cli <命令> [子命令] [标志...]

命令:
  issue create <title>    创建一个工作项
  issue list              查询工作项列表

全局标志:
  -h, --help              显示帮助，可放在任意命令后

参数校验与退出码

$ req-cli issue create "登录页白屏"
错误: 缺少必填标志 --project-id
提示: 用法: req-cli issue create <title> --project-id <uuid> --tracker <2|3|5|6|7> --priority <1|2|3>
退出码 2（参数非法，写 stderr）

$ req-cli issue list --project-id 0123… （未配 AK/SK）
{"ok":false,"error":{"kind":"config","exitCode":5,"message":"缺少 AK/SK 配置"}}
